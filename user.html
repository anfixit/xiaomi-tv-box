🙂 Ставим кино на приставку

Что понадобится:

  • компьютер или ноутбук с интернетом;
  • флешка (любая, хватит 1 ГБ);
  • приставка, подключённая к телевизору и к интернету, и пульт.

Займёт минут 30. Сломать ничего нельзя — просто делай по шагам, по порядку.

1Поставь на приставку «проводник»

Сама приставка не умеет открывать файлы с флешки — для этого нужна программа-проводник. Ставим её прямо на приставке, как на телефоне. Флешка и компьютер пока не нужны.

  1. На пульте нажми кнопку домик.
  2. Открой Google Play (если на главном экране не видно — зайди в «Приложения»).
    Попросит войти в Google? Войди тем же аккаунтом, что на телефоне (почта …@gmail.com). Проще всего: приставка покажет QR-код — наведи на него камеру телефона.
  3. Нажми лупу 🔍 и напиши File Manager Plus (или скажи голосом — кнопка с микрофоном на пульте).
  4. Выбери приложение с синей иконкой-папкой → «Установить». Подожди минуту.

✅ Проводник есть.

2Скачай папку «Для флешки» на компьютер

Открыть Google Диск
  1. На Диске найди папку «Для флешки».
  2. Нажми на неё правой кнопкой мыши → «Скачать».
  3. Подожди: Google сам упакует папку в архив. Скачается один файл, его название начинается с «Для флешки» и заканчивается на .zip.
  4. Открой папку «Загрузки» на компьютере, нажми на этот файл правой кнопкой → «Извлечь все…» → «Извлечь».

Появится обычная папка с файлами:

  • 1 TorrServe
  • 2 Lampa
  • 3 LazyMedia
  • 4 Seena
  • 5 HDRezka
  • 6 RuStore
  • Проводник (запасной) — он нужен, только если в шаге 1 не получилось

3Скинь файлы на флешку

  1. Вставь флешку в компьютер.
  2. Зайди в распакованную папку, нажми Ctrl + A (выделить всё), потом Ctrl + C (копировать).
  3. Открой флешку («Этот компьютер» → флешка), нажми Ctrl + V (вставить). Подожди, пока скопируется.
  4. Вынь флешку.

4Вставь флешку в приставку и открой первый файл

  1. Вставь флешку в USB-разъём на приставке (он там один).
  2. Открой File Manager Plus.
  3. Выбери флешку (называется USB или по имени флешки).
  4. Пультом выбери файл 1 TorrServe и нажми центральную кнопку.

5Разреши установку (один раз)

Приставка напишет что-то вроде «Установка из этого источника запрещена». Это нормально.

  1. Нажми «Настройки».
  2. Включи переключатель напротив File Manager Plus.
  3. Нажми на пульте назад ↩.
  4. Нажми «Установить».

Если такого окна нет, но и установка не идёт: Настройки → Конфиденциальность → Безопасность и ограничения → Неизвестные источники → включи File Manager Plus.

6Поставь остальные файлы по номерам

Так же по очереди открой и установи 2, 3, 4, 5, 6. Разрешать больше ничего не надо — просто «Установить».

7Остальное — из магазина на приставке

Эти приложения не надо качать на флешку. Ставь прямо на приставке:

  1. Домик → Google Play → лупа 🔍 → напиши название → «Установить».
  2. Не нашлось? Открой RuStore и поищи там. При первом запуске он попросит войти — проще всего через VK ID или по номеру телефона.

8Как смотреть

  1. Один раз открой TorrServe и сразу закрой — он должен просто запуститься.
  2. Открой Lampa, найди фильм, нажми «Смотреть».
  3. Если спросит, каким плеером открыть, — выбери ViMu.
  4. Не нашёлся фильм — поищи в LazyMedia или HDRezka.
  5. Телеканалы — Цифровое ТВ, спорт — Seena.

Эти приложения берут кино с чужих сайтов, поэтому иногда отдельный фильм может не открыться — выбери другую озвучку или качество из списка, или поищи в другом приложении.

Что-то пошло не так

ПроблемаЧто делать
Не получилось поставить проводник из Google PlayНа флешке есть файл «Проводник (запасной)», но открыть его без проводника нельзя 🙃 Позвони тому, кто дал эту инструкцию.
Приставка не видит флешкуВынь и вставь снова. Не помогло — попробуй другую флешку.
Пишет «Приложение не установлено»Скорее всего, оно уже стоит. Найди его в списке приложений.
Пишет «Ошибка синтаксического анализа»Файл скопировался не до конца. Скопируй его на флешку ещё раз.
Приложения нет ни в Google Play, ни в RuStoreПроверь название. Иногда оно на английском: Okko, Kion, Wink.
Приставка не включается, на экране английские слова или Can't load Android systemНичего не нажимай и позвони тому, кто дал эту инструкцию 🙂
Не отключай обновления приставки и ничего не удаляй из её настроек — это не нужно.
