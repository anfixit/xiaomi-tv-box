🙂 Ставим кино на приставку через флешку

Что понадобится:

  • компьютер или ноутбук с интернетом;
  • флешка (любая, хватит 2 ГБ);
  • приставка, подключённая к телевизору и к интернету, и пульт.

Займёт минут 20. Сломать ничего нельзя — просто делай по шагам.

1Сначала: поставь на приставку «проводник»

Сама приставка не умеет открывать файлы с флешки — для этого нужна программа-проводник. Ставится она из магазина Google Play прямо на приставке, как на телефоне. Флешка и компьютер для этого не нужны.

  1. На пульте нажми кнопку домик.
  2. Открой Google Play (если на главном экране не видно — зайди в «Приложения»).
    Попросит войти в Google? Войди тем же аккаунтом, что на телефоне (почта …@gmail.com). Проще всего: приставка покажет QR-код — наведи на него камеру телефона.
  3. Нажми лупу 🔍 и напиши File Manager Plus (или скажи голосом — кнопка с микрофоном на пульте).
  4. Выбери приложение с синей иконкой-папкой → «Установить». Подожди минуту.

✅ Проводник есть — теперь можно качать программы.

2Скачай программы на компьютер

VK Видео и плеер VLC с флешки не ставятся — их возьмём из магазина, это шаг 8.

Всё это сейчас стоит и работает на моей приставке. Но эти приложения берут кино с чужих сайтов, поэтому иногда отдельный фильм может не открыться — тогда выбери другую озвучку или поищи в другом приложении.

Файлы окажутся в папке «Загрузки» на компьютере. Они заканчиваются на .apk.

Файлы, которые заканчиваются на .apks (с буквой s на конце), не качай — через флешку они не ставятся.

3Скинь их на флешку

  1. Вставь флешку в компьютер.
  2. Открой папку «Загрузки».
  3. Выдели скачанные файлы, нажми правой кнопкой → «Копировать».
  4. Открой флешку («Этот компьютер» → флешка), нажми правой кнопкой на пустом месте → «Вставить».
  5. Вынь флешку.

4Вставь флешку в приставку и открой файл

  1. Вставь флешку в USB-разъём на приставке (он там один).
  2. Открой File Manager Plus.
  3. Выбери флешку (называется USB или по имени флешки).
  4. Пультом выбери файл TorrServe и нажми центральную кнопку.

5Разреши установку (один раз)

Приставка напишет что-то вроде «Установка из этого источника запрещена». Это нормально.

  1. Нажми «Настройки».
  2. Включи переключатель напротив File Manager Plus.
  3. Нажми на пульте назад ↩.
  4. Нажми «Установить».

Если такого окна нет, но и установка не идёт: Настройки → Конфиденциальность → Безопасность и ограничения → Неизвестные источники → включи File Manager Plus.

6Поставь остальные

Так же по очереди открой и установи все остальные файлы с флешки. Разрешать больше ничего не надо — просто «Установить».

✅ Готово! Флешку можно вынуть.

7Как смотреть

  1. Один раз открой TorrServe и сразу закрой — он должен просто запуститься.
  2. Открой Lampa, найди фильм, нажми «Смотреть».
  3. Если Lampa спросит, каким плеером открыть, — выбери ViMu.
  4. Не нашёлся фильм — поищи в LazyMedia.
  5. Телеканалы — Цифровое ТВ, спорт — Seena.

Приложения бесплатные. Иногда какой-то фильм не грузится — выбери другой вариант из списка (другая озвучка или качество).

8YouTube, VK Видео, Окко, Кинопоиск и др.

Это обычные официальные приложения. Их не надо качать на флешку — они ставятся прямо на приставке из магазина, как на телефоне.

YouTube на приставке уже есть — ничего ставить не нужно.

Остальные:

  1. На пульте нажми домик → открой Google Play.
  2. Наверху нажми лупу 🔍 и напиши название (можно сказать голосом — кнопка с микрофоном на пульте).
  3. Выбери приложение → «Установить».
  4. Открой его и войди в свой аккаунт (как на телефоне). Если подписка платная — она та же, что на телефоне, второй раз платить не надо.

Нет в Google Play? Открой RuStore (ставили в шаге 6) и найди там тем же способом. При первом запуске RuStore попросит войти — проще всего через VK ID или по номеру телефона.
