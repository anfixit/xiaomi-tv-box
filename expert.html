0. Подготовка

  1. tools\01-install-driver.cmd — от администратора.
  2. На приставке: Настройки → Система → Об устройстве → 7 раз по «Сборка»; затем Для разработчиков → Отладка по USB.
  3. Кабель USB A–A (порт на приставке один). Без кабеля — сетевой adb: tools\adb\adb.exe connect <IP>:5555.
  4. tools\02-device-state.cmd — показывает режим (adb / fastboot / adnl). Подтверди на ТВ «Разрешить отладку», иначе unauthorized.

1. Прошивка

Обновления шлёт Xiaomi (com.xiaomi.mitv.updateservice), обычно хватает Настройки → Система → Обновление. Отключать не надо.

Ручной sideload

  1. Полный OTA-zip (~1 ГБ, в META-INF/com/android/metadata есть pre-device=jaws и нет pre-build) — лежит в firmware\.
  2. tools\04-reboot-to-recovery.cmd → на ТВ Apply update from ADB.
  3. Перетащить zip на tools\05-sideload-ota.cmd. 10–20 мин, затем Reboot system now. Первая загрузка до 10 мин — питание не трогать.
В recovery пульт (Bluetooth) не работает, USB-клавиатура не определяется. Беспроводная мышь работает.

2. Приложения

tools\10-install-apps.cmd ставит все .apk/.apks из apps\ рекурсивно (папки на _ пропускаются). Сам обходит:

  • .apks — распаковывает и ставит через install-multiple;
  • INSTALL_FAILED_DEPRECATED_SDK_VERSION — повтор с --bypass-low-target-sdk-block;
  • INSTALL_FAILED_UPDATE_INCOMPATIBLE — подпись не совпала (mod-сборка vs оригинал): только удалить и поставить заново.

По одному: tools\adb\adb.exe install -r -d "файл.apk". Забрать самообновившиеся APK обратно: 11-pull-apps-from-box.cmd.

3. Чистка предустановленного

tools\12-debloat.cmd (снимок пакетов сохраняет в backups\), откат — 13-restore-debloat.cmd. Root не нужен: pm uninstall --user 0 / pm disable-user --user 0, обратимо, сбрасывается factory reset'ом. Убирает вкладку Mi Home, телеметрию Xiaomi, бесполезные Google-довески.

Не трогать: com.xiaomi.mitv.updateservice, com.google.android.tv.remote.service, com.mi.bluetooth, gms/gsf/vending, com.android.tv.settings, launcherx, com.droidlogic.*, mitv.service, katniss. Чужие пресеты вслепую не применять.

Плитки с облачком (Disney+, iQIYI) — реклама лаунчера: долгое нажатие → «Убрать».

4. Кнопки пульта

tools\14-remap-buttons.cmd ставит Buttons Remapper и включает ему accessibility через adb. Дальше в приложении: правило → нажать кнопку → «запустить приложение».

  • Кнопка не ловится — отключи целевое приложение: pm disable-user --user 0 com.netflix.ninja.

5. Если не грузится

Главное: в 9 из 10 случаев Can't load Android system. Your data may be corrupt лечится Factory data reset в этом же меню. Система цела — не монтируется userdata от предыдущей сборки.

  1. Try again.
  2. Factory data reset (мышью).
  3. Нечем нажать — 06-erase-userdata.cmd (стирает только userdata).
  4. 07-switch-ab-slot.cmd — ничего не пишет, но нужен разблокированный загрузчик.
  5. 08-fastboot-flash-26.2.5.cmd / 09-…25.3.3.cmd — крайняя мера, нужна разблокировка (потеря green, L1 и данных).
Никогда не запускай вендорские go.cmd/.bat из архивов прошивок: они в конце делают fastboot flashing lock. Блокировка при несовпадении разделов с vbmeta = твёрдый кирпич. Наши скрипты lock не делают намеренно.

Recovery аппаратно: обесточить, зажать зубочисткой кнопку в отверстии снизу, подать питание, держать ~10 с. Maskrom: то же с кабелем к ПК, проверка tools\adnl\adnl.exe devices; drivers\aml-new_factory-reset_02\go.cmd обнуляет metadata. Последний рубеж — USB Burning Tool (нужен aml_upgrade_package.img, его в комплекте нет).

Не видно устройство: кабель A–A не «только зарядка»; в Диспетчере устройств поставить драйвер вручную из drivers\huawei-adb-interface-9-1214504.

Почему OTA однажды убил приставку

В слоте A стояла 25.3.3 userdebug, залитая через fastboot. OTA 26.4.17 встал в слот B, но не смог расшифровать userdata (FBE-ключи привязаны к состоянию verified boot). Factory reset → чистый userdata → OTA прошёл штатно. Теперь обе стороны user, следующие обновления безопасны.
